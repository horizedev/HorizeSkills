Interactive operating board

Move evidence, not excitement, from idea to MVP.

Each card is a bounded agent assignment. Each gate is a founder decision. The output from one stage is the only approved input to the next, so the product is built on evidence instead of conversational memory.

How to use this guide

Choose the active stage. Review its required handoff. Ask the assigned Codex role to create the draft artifact. Review the evidence, then simulate the founder decision to advance, revise, or pivot.

The operator's rule

Agents may research, synthesize, design, code, and test. The founder retains authority where capital, customers, legal exposure, public claims, and production systems are involved.

Awaiting approved upstream inputs
Active: agent drafts its handoff
Founder approved: valid downstream input
Revision requested: do not advance
Hard boundary. This guide only simulates internal workflow state. Real outreach, payment setup, domains, cloud accounts, production deployment, and launch publication require an explicit founder approval outside the simulation.
